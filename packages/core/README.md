# @simbridge/core

The core services that run on the Windows PC and that every entry point (CLI, MCP server, desktop app) shares: C1 Auth and Repo Manager, C2 Stack Detector, C3 Build Orchestrator, C4 Session Manager, C9 Telemetry Collector, C10 Recorder and Replayer, C11 Conditions Controller and C12 Budget Guard. Pure logic lives here so it can be tested without GitHub or a device. Design: [SDS](../../docs/SDS.md) sections 3.1 to 3.4 and 3.9 to 3.12. Status: empty skeleton, work starts in R1.
