# @simbridge/desktop

The Windows desktop app (Electron + React): the live simulator or device screen, logs, stats, recordings and the minute budget in one window. It is built last, on top of the same core services as the CLI and MCP server. Design: [SDS](../../docs/SDS.md) sections 2 and 8.2, requirements in SRS 3.13 (M13). Status: empty skeleton, built last.
