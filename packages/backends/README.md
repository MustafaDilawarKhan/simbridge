# @simbridge/backends

The device backends, one per run mode, all implementing the single `DeviceBackend` interface so agent tools never change: C5 Cloud Simulator (Mode B), C6 Real Device (Mode A), C7 Headless Runner (Mode C) and C13 Android (R4, only if time allows). Design: [SDS](../../docs/SDS.md) sections 3.5 to 3.7, 3.13 and 3.14. Status: empty skeleton, work starts in R1 with C5.
